# LivingVillages 0.1 — бесплатная версия

Самостоятельный проект Free под лицензией MIT: одна культура Полевичей, уровни деревни 1–3, до 12 жителей, до 5 деревень на мир. Работают хозяйство, питание и голод, добыча подтверждённых ресурсов, обычный крафт, строительство, дома жителей, торговля, монеты, доверие, поручения, NPC, местная охрана, карта и таблички. Клиентские моды и ресурспак не нужны.

Платные реализации в этой папке отсутствуют. Изменение лимитов открытого кода разрешено MIT и не превращает его в Premium: здесь нет остальных культур, расширенной архитектуры, улучшений зданий, личных заказов домов, власти, армий, войн, монументов и редкого оружия. Рекламные напоминания выключаются через `edition.reminders-enabled: false`.

Сборка: установите Java 25, выполните `./gradlew clean test build` (Windows: `gradlew.bat`). Готовый файл: `build/libs/LivingVillages-0.1.jar`. Проверка состава: `python3 scripts/check_distribution.py build/libs/LivingVillages-0.1.jar`.

Установка: остановите Paper 26.3, сохраните резервную копию мира и `plugins/LivingVillages`, оставьте в `plugins` один JAR LivingVillages и запустите сервер. По умолчанию используется английский. Для русского поменяйте `language: en` на `language: ru` в `plugins/LivingVillages/config.yml`, затем выполните `/lv reload` или перезапустите сервер. Folia не поддерживается.

`/lv help` показывает команды с описаниями. `/lv menu` открывает список обнаруженных лично игроком деревень; действия доступны на территории выбранной деревни. `/lv status` объясняет остановку развития. `/lv admin`, `/lv create polevichi`, `/lv coins`, `/lv pause`, `/lv npc status`, `/lv npc repair`, `/lv diagnostics` — административные инструменты. Разрешения: `livingvillages.admin` и `livingvillages.bypass`, по умолчанию у операторов.

Дарить материалы можно с 50 доверия, назначать общее строительство — со 100. Поручения доступны незнакомцам, по одному активному поручению на поставку. Торговец покупает текущие потребности и продаёт свободный запас, защищая еду для жителей.

Для GitHub публикуйте содержимое **этой папки**. Родительский рабочий проект, старые полные архивы, Premium JAR, базы и тестовые миры сюда не относятся. Из старой Free 0.1 поддерживается формат деревни 15. Premium и неподдерживаемые форматы отвергаются; не подменяйте маркер редакции. Перед обновлением сделайте копию данных.
